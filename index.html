gta6-shorts

gta6-shorts is a personal automation tool used by its owner to publish short gaming news videos about Grand Theft Auto VI to the owner's own YouTube channel.

It uses YouTube API Services (the YouTube Data API v3) only to upload videos to that single channel. It is not offered to the public and does not access anyone else's account or data.
