Privacy policy – gta6-shorts

Last updated: 4 October 2026

What this app is

gta6-shorts is a personal tool run by its owner to upload videos to the owner's own YouTube channel. It is not available to other users.

Data we access

The app requests one Google permission: youtube.upload, which allows it to upload videos to the authorised channel. It does not read, store or share any other Google account data, personal information, viewer data or analytics.

How data is stored

The access credentials are stored as encrypted secrets in the owner's private GitHub repository and are used only to upload videos. No data is sold or shared with third parties.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be removed at any time from your Google account's third-party access page.
