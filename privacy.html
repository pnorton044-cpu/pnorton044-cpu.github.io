Privacy policy – gta6-shorts

Last updated: 4 October 2026

What this app is

gta6-shorts is a personal tool run by its owner, Paddy Norton, to upload videos to the owner's own YouTube channel. It is not available to the public and has no other users.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

What data we access

The app requests one Google permission: https://www.googleapis.com/auth/youtube.upload, which lets it upload videos to the authorised channel. It does not read, collect, store or share any YouTube data, personal information, viewer data, comments or analytics, and it accesses no other accounts.

How data is used and stored

The only stored item is the OAuth access credential for the owner's own channel. It is kept as an encrypted secret in the owner's private GitHub repository and is used solely to upload the owner's videos. No data is sold, shared with third parties, or used for advertising.

Data retention and deletion

The app keeps no user data. The stored credential is deleted when the owner removes it from the GitHub repository or revokes access. Access can be revoked at any time from the Google security settings page, which immediately stops the app from uploading. If you believe any of your data has been processed by this app, email us and we will respond and delete it within 7 days.

Cookies and tracking

This app and website do not use cookies, tracking or analytics.

Changes

Any changes to this policy will be posted on this page with an updated date.
